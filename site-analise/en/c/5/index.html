Brazil's runoff reversal, chapter 5 of 9

Is the vote for deputy and senator linked to the change between the rounds?

No clear link appeared, on Lula's side or on Flávio's. Where voters already voted more for left-wing parties for federal deputy, Lula did not clearly grow more than in municipalities in the same state with the same first-round vote for him; where they voted more for right-wing parties, the same holds for Flávio. If there is a link, it is small. The same holds for state deputy and senator.
