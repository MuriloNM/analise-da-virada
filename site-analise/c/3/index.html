Como os votos dos outros candidatos do 1º turno se dividiram entre os dois?

Não dá para saber com segurança. Dos votos dos outros candidatos do 1º turno, a parte que foi para o Lula depende de como se faz a conta: de 46 a 61 de cada 100 (e de 39 a 54 para o Flávio). E não ficou claro se o Lula cresceu mais onde os outros candidatos tiveram mais votos.
